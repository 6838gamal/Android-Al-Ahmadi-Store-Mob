# PROJECT AUDIT PROMPT

## Android Al-Ahmady Full System Verification

مهم جداً:

لا تقم ببناء أي ميزة جديدة.

لا تقم بإعادة هيكلة المشروع.

لا تقم بتعديل أي ملف.

مهمتك الحالية هي:

إجراء مراجعة شاملة (Full Audit) للمشروع الحالي والتحقق من أن جميع المتطلبات والمزايا تم تنفيذها فعلياً وتعمل كما هو متوقع.

قم بفحص المشروع كاملاً:

## تدقيق الأدوار والصلاحيات

تحقق من أن:

### Customer

يستطيع فقط:

* تصفح المنتجات
* الحجز
* إنشاء الطلبات
* متابعة الطلبات
* متابعة الصيانة
* تقديم طلب ضمان
* الإحالة
* الإشعارات

ولا يستطيع الوصول لأي وظيفة إدارية.

━━━━━━━━━━━━━━━━━━

### Staff

تحقق أنه يستطيع فقط:

* الرد على الفحص
* تسجيل الشاشة كمباعة
* إعادة الشاشة للمخزون
* تحديث حالة الطلب
* تحديث حالة الصيانة

وتحقق أنه لا يستطيع:

* رؤية الأرباح
* رؤية التقارير المالية
* تعديل الأسعار الأساسية
* إدارة المستخدمين
* إدارة الصلاحيات
* إدارة النسخ الاحتياطية

حتى عند استدعاء API مباشرة.

━━━━━━━━━━━━━━━━━━

### Branch Manager

تحقق أنه يرى بيانات فرعه فقط.

ولا يستطيع الوصول لبيانات الفروع الأخرى.

━━━━━━━━━━━━━━━━━━

### Super Admin

تحقق من امتلاكه لجميع الصلاحيات.

━━━━━━━━━━━━━━━━━━

## تدقيق نظام الصلاحيات

تحقق من:

* RBAC
* Permissions

وتأكد أن التحقق يتم داخل:

* Flutter UI
* API
* Backend Services

وليس فقط بإخفاء الأزرار.

━━━━━━━━━━━━━━━━━━

## تدقيق نظام المنتجات والشاشات

تحقق من:

* Unique Item ID

وتأكد أن:

* لا يوجد تكرار
* يتم توليده تلقائياً
* لا يمكن التلاعب به

تحقق من:

* Available
* Reserved
* Sold

وتحقق من انتقال الحالات بشكل صحيح.

━━━━━━━━━━━━━━━━━━

## تدقيق نظام الطلبات

تحقق من:

وتأكد أن:

* الرقم فريد
* لا يتكرر
* لا يحدث تصادم

تحقق من:

* Timeline
* Tracking History
* Notifications
